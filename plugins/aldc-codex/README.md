# ALDC for Codex

Generated by scripts/sync-codex.js from canonical terminal sources. No manual
edits. Node 20+ is the only bootstrap interpreter; no Python/PATH setup is needed.

From a checkout, preview a separate project:

`node plugins/aldc-codex/scripts/init.js --project /path/to/project`

Repeat with --apply after reviewing the plan. This installs one local ALDC skill,
12 .codex/agents profiles, AL rules and a managed AGENTS.md block (or the existing
AGENTS.override.md). Models, sandbox, approvals and MCP settings are inherited.
--force backs up reviewed collisions; --verify checks receipt drift; --rollback
restores the preceding transaction if later project edits would not be lost.

The package manifest supports plugin distribution, but no marketplace entry is
created. Use either plugin skill discovery or local bootstrap, never both in the
same project. Plugin discovery alone does not install the project TOML profiles.

Restart Codex, inspect /skills and loaded instruction sources, then request a
bounded read-only role invocation and inspect its full loaded profile. Counting
files is not this host test. Full Conductor/Architect bodies remain intact and
must load completely in the installed host. See ../../docs/plugin-packaging.md
for installation behavior and compatibility requirements.
