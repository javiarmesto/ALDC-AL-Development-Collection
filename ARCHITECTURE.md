# ALDC — Repository Architecture Map

> One-page guide to what is **source**, what is **generated/derived**, and which
> **distribution channel** consumes each tree. If you are editing a derived tree by hand,
> stop — edit the source and re-derive.

## Sources of truth

| Tree | Role |
|------|------|
| `agents/`, `skills/`, `instructions/` | **Canonical primitives** (GitHub Copilot format: `.agent.md`, `SKILL.md`, `applyTo` globs). Workflows are skills invoked as slash commands; prompt files are no longer shipped. Every other surface derives from here. |
| `docs/` | Source of the public website (MkDocs). |
| `docs/framework/ALDC-Core-Spec-*.md` | Normative specification. |
| `aldc.yaml`, `collections/al-development.collection.yml` | Manifests: what the framework contains and ships. |

## Derived / consumer surfaces

| Surface | Derives from | How | Consumed by |
|---------|--------------|-----|-------------|
| **VS Code extension** (local `toolbox/al-coding-agent-collection/`, gitignored) | `packages/foundation/` + `docs/templates/`, `docs/schema/`, `tools/aldc-validate/`, `aldc.yaml` | `prepare-package.js` copies them into the VSIX at build time | **VS Code Marketplace — primary channel (600+ installs)** |
| `claude-plugin/` | canonical primitives | generated by `npm run sync:claude` (`scripts/sync-plugin-support.js`) | Claude Code plugin marketplace |
| `copilot-cli-plugin/` | canonical primitives | generated by `npm run sync:copilot-cli` | Copilot CLI (`aldc-cli`) |
| `plugins/aldc-codex/` | canonical primitives | generated by `npm run sync:codex` | Codex |
| `.claude/` | `claude-plugin/` | `npm run sync:claude-workspace` (mirror; CI checks drift) | developing THIS repo with Claude Code |
| `packages/foundation/` | canonical primitives | `npm run sync:foundation`; CI fails on drift (`--check`). **The VS Code extension packages FROM here** — never delete, never let it drift from the root trees |
| `docs/instructions/` | `instructions/` | manual doc-formatted copies | website navigation |
| `gh-pages` branch | `docs/` | **build output** of `docs.yml` (MkDocs) on every push to `main` — never edit by hand | GitHub Pages site |

## Distribution channels

1. **VS Code Marketplace extension** — primary. `prepare-package.js` (in the local
   extension folder) copies `packages/foundation/` primitives into the VSIX;
   a root↔foundation drift check runs in CI so the VSIX does not ship content that
   diverged from the canonical trees.
2. **`npx --no aldc install`** (`scripts/install.js`, from a checkout or a local `.tgz`; the npm registry copy is deprecated) —
   copies canonical root trees into a consuming AL project.
3. **Claude Code plugin** (`claude-plugin/` + `.claude-plugin/marketplace.json`) — reaches
   the non-VS Code audience.
4. **Copilot CLI plugin** (`copilot-cli-plugin/`) and **Codex** (`plugins/aldc-codex/`) —
   terminal hosts, installed from a checkout.
5. **Website** (`docs/` → `gh-pages` via `docs.yml`).

## Editing rules

- Change primitives → edit the **root trees only**, then regenerate
  `packages/foundation/` (`npm run sync:foundation`; the extension packages from
  there) and the host distributions (`npm run sync:plugins`). Run the conformance
  check before building the VSIX.
- Change website → edit `docs/` on `main`; deployment is automatic.
- Never commit to `gh-pages`; never edit `packages/foundation/` directly — it must
  stay byte-identical to the root trees.
