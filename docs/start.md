<div class="aldc-source-setup" data-aldc-source><h2>Prepare the 5.0.0 source</h2><p>For Claude Code, Copilot CLI and Codex: Git, Node.js 20+ and an installed, authenticated host. Use a separate AL project with app.json. Run these PowerShell commands from a tools folder outside that project, once. Choose a new ALDC-5.0.0 folder; do not overwrite an existing clone.</p><div class="aldc-command"><button type="button" data-aldc-copy hidden>Copy</button><pre><code>git clone https://github.com/javiarmesto/ALDC-AL-Development-Collection.git ALDC-5.0.0
if ($LASTEXITCODE -ne 0) { throw &quot;Clone failed&quot; }
git -C .\ALDC-5.0.0 checkout v5.0.0
if ($LASTEXITCODE -ne 0) { throw &quot;Checkout failed&quot; }
$aldc = (Resolve-Path .\ALDC-5.0.0).Path
$project = (Resolve-Path &#x27;C:\Path\To\YourALProject&#x27;).Path</code></pre></div><p>Replace the example project path before running. Keep this PowerShell session open: the following commands use $aldc and $project. The checkout is detached intentionally.</p><a href="https://github.com/javiarmesto/ALDC-AL-Development-Collection/tree/v5.0.0">Inspect the 5.0.0 source · v5.0.0</a></div>

<div class="aldc-install-panel__heading"><h2>GitHub Copilot <span>VS Code</span></h2><span class="aldc-channel-badge">Marketplace · 5.0.0</span></div><section class="aldc-step"><span class="aldc-step__number">01</span><div><h3>Install the extension</h3><p>You need VS Code, GitHub Copilot access and an AL project. Install from the official listing; this command installs the published channel.</p><div class="aldc-command"><button type="button" data-aldc-copy hidden>Copy</button><pre><code>code --install-extension javierarmestogonzalez.al-development-collection</code></pre></div><p><a href="https://marketplace.visualstudio.com/items?itemName=javierarmestogonzalez.al-development-collection">Open Marketplace</a> · For VS Code Insiders, use code-insiders instead of code.</p></div></section><section class="aldc-step"><span class="aldc-step__number">02</span><div><h3>Install the toolkit in your AL project</h3><p>Open the project folder containing app.json. From the Command Palette run <strong>AL Collection: Open Project Manager</strong>, choose the profile, preview the file list and confirm; the panel also verifies, restores and runs Doctor. <strong>AL Collection: Install Toolkit to Workspace</strong> does the same from the palette. Reload the window afterwards. Installing the extension alone does not populate the project.</p></div></section><section class="aldc-step"><span class="aldc-step__number">03</span><div><h3>Check discovery before implementation</h3><p>The <strong>ALDC Visor</strong> view in the Explorer lists the plan artifacts of each requirement as they are created. Agent discovery does not prove compilation or test execution.</p></div></section><details class="aldc-route-note"><summary>Installing from a VSIX file?</summary><p>Use Extensions: Install from VSIX with the file, reload, then update the project toolkit. <section class="aldc-first-task"><div class="aldc-start__eyebrow">02 / YOUR FIRST REQUEST</div><h2>Start with one design decision.</h2><p>In the selected host, ask the ALDC Architect to work on a bounded requirement. First verify which instructions are available.</p><div class="aldc-command"><button type="button" data-aldc-copy hidden>Copy</button><pre><code>Use the ALDC Architect role. Identify the ALDC instructions and skills you actually loaded, or state what is missing.

Requirement: add a delivery note to customers so a user can consult it on the Customer Card.

Read the target version from app.json. Assess the scope and propose the necessary specifications and dependencies. Do not generate AL, compile, deploy or change configuration. Stop for my review.</code></pre></div></section>
<div class="aldc-install-footnotes"><h2>What installation does not do</h2><p>BC28 / BC29 profiles guide ALDC; they do not install the AL extension, compiler, symbols or a Business Central environment. Terminal hosts use their own available tools; VS Code tools are not portable by name. Configure each project for its target.</p><p>BCQuality is optional and separate. Doctor requires Python 3.9+ and reports configuration and observations per operation.
